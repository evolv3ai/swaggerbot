# swaggerbot.dev — rebrand UI kit
Content, IA and copy from the live site (https://swaggerbot.dev/); visuals from the new SwaggerBot logo system (the site's amber theme is retired).
Screens: Search (home), Lookup result (Resolved / Unconfirmed / Ambiguous / No Spec), Vendors (Index table), Docs (MCP / HTTP API).
Click-through: type an API name → Look up; try Plaid, Twilio, Mercury, Acme. Dark by default, as on swaggerbot.dev; the theme toggle in the header switches to light. Data in `data.js` is representative.
