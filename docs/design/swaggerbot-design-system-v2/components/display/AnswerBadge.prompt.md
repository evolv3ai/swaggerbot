AnswerBadge — shows one of SwaggerBot's five Lookup answers with its fixed colour; use for every Lookup result.
```jsx
<AnswerBadge answer="resolved"/>
<AnswerBadge answer="unconfirmed" short/>
```
Resolved=green, Unconfirmed=amber, Ambiguous=blue, No Spec=neutral, Unknown=outline. Don't invent other states.
