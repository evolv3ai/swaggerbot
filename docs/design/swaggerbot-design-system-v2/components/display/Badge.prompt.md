Badge — tiny pill status label (uppercase Montserrat bold).
```jsx
<Badge tone="success" dot>Valid</Badge>
```
Tones: accent, neutral, success, warning, danger, solid, outline (transparent, 1.5px strong edge, muted text). `dot` adds the round status "eye". For a Lookup answer use AnswerBadge; for a Spec's Provenance use ProvenanceBadge.
