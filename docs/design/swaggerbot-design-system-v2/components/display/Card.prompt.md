Card — 16px-radius surface for grouped content; string children render as muted body copy.
```jsx
<Card eyebrow="Official" title="The Plaid API" interactive>plaid.com · verified 24 Sept 2026</Card>
```
Variants: default (1px border), raised (shadow), outline (2px blue with a soft lift — use once per view for a highlighted item, like the Lookup box), content (12px radius, 16px padding — an answer, a table, a command).
