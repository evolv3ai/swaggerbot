ProvenanceBadge — a Spec's Provenance, next to every Spec (never behind a click); the same badge on every page.
```jsx
<ProvenanceBadge provenance="Official"/>
<ProvenanceBadge provenance="Community"/>
```
Official = accent with the dot (the eye), Endorsed = neutral, Mirror = outline, Community = dashed outline. The tier's name is always written: the style is never the only signal.
